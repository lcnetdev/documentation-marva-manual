# Instance Description

The Instance Description section of Marva covers data elements related to the physical or digital manifestation of a resource. Below are all the components available in the Instance Description.

## Components

- [Title Information](title-information.md) -- Transcribe title information from the Instance (MARC 245, 246)
- [Title Information: Best Practice for Non-Latin Titles](title-non-latin.md) -- Guidance on recording titles in non-Latin scripts
- [Statement of Responsibility](statement-of-responsibility.md) -- Transcribe statement of responsibility (MARC 245 $c)
- [Edition Statement](edition-statement.md) -- Transcribe edition statement (MARC 250)
- [Provision Activity](provision-activity.md) -- Record Publication, Production, Distribution, and Manufacture data (MARC 264, 260, 008)
- [Copyright Date](copyright-date.md) -- Record copyright date (MARC 264)
- [Mode of Issuance](mode-of-issuance.md) -- Categorization of how an Instance is issued (Ldr/07)
- [Identifiers](identifiers.md) -- LCCN, ISBN, OCLC number, and other identifiers (MARC 010, 020, 024, 035)
- [Notes about the Instance](notes-about-instance.md) -- Record notes related to the Instance (MARC 5XX)
- [Supplementary Content URL](supplementary-content-url.md) -- Record supplementary online content URLs (MARC 856)
- [Immediate Source of Acquisition Note](acquisition-note.md) -- Acquisition note guidance (MARC 541)
- [Media Type](media-type.md) -- Record the media type (MARC 337)
- [Physical Description](physical-description.md) -- Record extent and other physical details (MARC 300)
- [Dimensions](dimensions.md) -- Record dimensions of the Instance (MARC 300 $c)
- [Carrier Type](carrier-type.md) -- Record the carrier type (MARC 338)
- [Access Policy](access-policy.md) -- Record access and use restrictions (MARC 506, 540)
- [URL of Instance](url-of-instance.md) -- Record electronic access URL (MARC 856)
- [Projected Publication Date](projected-publication-date.md) -- Record projected publication date for CIP (MARC 263)
- [Admin Metadata](admin-metadata.md) -- Pre-populated administrative metadata (Ldr/17, Ldr/18, 040)
