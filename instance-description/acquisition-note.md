# Immediate Source of Acquisition Note

## Scope

Do not use this component. The Immediate source of acquisition note in the Marva Instance is provided for institutions that are not using BIBFRAME items for cataloging.

In MARC to BIBFRAME conversion, an Immediate Source of Acquisition Note in MARC 541 is placed on the BIBFRAME Item.

## Folio / MARC

- 541 field, Immediate Source of Acquisition Note
