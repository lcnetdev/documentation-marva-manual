# Access Policy

## Scope

This component gives information on parameters associated with access to a resource.

## Folio / MARC

- 506 field, Restrictions on Access Note
- 540 field, Terms Governing Use and Reproduction Note

## Access Policy

Record information as a literal value (note) about the terms governing use and reproduction of the resource.

## Qualifier

Record standardized terminology for use and reproduction rights as a literal value.
