# Physical Description

## Scope

Physical description includes the Extent of the resource as well as Other physical details. Extent is a core element in Original RDA only if the Instance is complete or if the total extent is known. Record subunits only if readily ascertainable and considered important for identification or selection. Illustrative content is a core element for LC for resources intended for children.

## Folio / MARC

- 300 field, subfield $a, Extent
- 300 field, subfield $b, Other physical details
- 300 field, subfield $e, Accompanying material

## Extent

Record the extent of the Instance here. Follow traditional punctuation guidelines but do not use ISBD punctuation. This is a literal field.

## Note

Use this field for recording illustrative content if considered important for identification or selection.

![Physical description component showing Extent "125 pages", Note "illustrations (some color), color maps", and Note type field](../images/page096_img05.png)

## Note Type

You do not need to use the "Note type: physical details" field for information that would be recorded in the MARC 300 field subfield $b, Other physical details. The system will automatically generate the MARC 300 field even if a physical details note is not manually entered.

## Accompanying material

Accompanying material that is placed in the MARC 300 $e field is treated as a note on the Instance in Marva.
