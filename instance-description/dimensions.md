# Dimensions

## Scope

Dimensions is a core element for LC for resources other than serials and online resources.

## Folio / MARC

- 300 field, subfield $c, Dimensions

## Dimensions

Record the dimensions of the Instance here. This field should only be used for the dimensions of the main resource, and the dimensions of any accompanying material should be recorded as a note on the Instance. Follow traditional punctuation guidelines but do not use ISBD punctuation. Do not add ending punctuation, even if the last element is cm. This is a literal field.
