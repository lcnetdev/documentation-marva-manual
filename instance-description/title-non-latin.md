# Title Information: Best Practice for Non-Latin Titles

## Repeating Fields within a Component

When recording titles in non-Latin script, repeat the field within a component to add the non-Latin title. Do not repeat the component, because this will prevent the 880 field from showing up in the MARC Preview and in the Modern MARC record. This best practice applies to [Provision Activity](provision-activity.md) as well. For [Statement of Responsibility](statement-of-responsibility.md), the field can be repeated, or the component can be repeated. When a MARC record with non-Latin script is imported into Marva, the Statement of Responsibility component will be repeated.
