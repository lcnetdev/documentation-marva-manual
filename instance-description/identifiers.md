# Identifiers

## Scope

There are seven values for Identifier:

![Identifiers dropdown showing: LCCN (selected), ISBN, OCLC number, Other identifier, Local system number, EAN, and National bibliographic number](../images/page087_img02.png)

Each recorded identifier value appears in its own Identifier component.

## Folio / MARC

- 010 field, Library of Congress Control Number
- 020 field, International Standard Book Number (ISBN)
- 024 field, Other Standard Identifier
- 035 field, System Control Number

## LCCN

Key in or scan the LCCN in this field.

![LCCN field with value "  2015336122" (with two leading spaces)](../images/page087_img03.png)

Follow the MARC spacing conventions for LCCN values. There are two leading spaces before 2015336122 in the example above.

### Invalid/canceled?

If the LCCN is invalid or has been canceled (the LCCN in MARC would appear in the subfield $z of the 010 field), from the drop-down list, select "canceled or invalid." If the LCCN is valid, do not select a value for this field.

![LCCN field with value "2012795478" and Invalid/canceled? set to "canceled or invalid (cancinv)"](../images/page088_img01.png)

## ISBN

Key in the ISBN number without an internal punctuation.

![ISBN field with value "9781631980329"](../images/page088_img02.png)

### Qualifier

Add any qualification here. Do not include parentheses.

![Qualifier field with value "paperback"](../images/page089_img01.png)

### Invalid/canceled?

This is a drop-down list to controlled values. If the ISBN is invalid or canceled, select the value "canceled or invalid" from the drop-down list.

![Invalid/canceled? field set to "canceled or invalid (cancinv)"](../images/page089_img02.png)

![Example showing two Identifiers components: first with ISBN "9781631980329", Qualifier "paperback"; second with ISBN "1631980327", Qualifier "soft cover"](../images/page089_img03.png)

![Example showing three LCCN Identifier components: first with LCCN "2018010147" (valid); second with LCCN "2019043996" marked "canceled or invalid"; third with LCCN "2021050651" marked "canceled or invalid"](../images/page089_img04.png)

If an additional ISBN is recorded, add a new component.

![Example showing multiple Identifier components: LCCN "2015043605" and ISBN "9781631980329" with Qualifier "paperback", using Add Another Component to add additional identifiers](../images/page089_img05.png)

Follow this guidance for recording any other identifiers associated with the Instance.
