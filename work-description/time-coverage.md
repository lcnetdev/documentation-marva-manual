# (Time) Coverage of the Content

## Scope

This component is used to record time content associated with the Work.

## Folio / MARC

- 045 field, Time Period of Content
- 500 field, General note

## (Time) Coverage of the Content

(Time) coverage of the content is recorded as a literal value.

Often a note at the Instance entity will provide more information on the (Time) coverage of the content.

![Time coverage of the content showing a literal value field](../images/page068_img01.png)

This component can be duplicated, but one component should be sufficient to record (Time) coverage of the content information.

To change information in this component, delete using the keyboard since this is a literal value.

If the component is not needed, just delete the information in the component.
