# Contributors

## Scope

This area is used for the person(s), family(ies), corporate body(ies), jurisdiction(s), or conference(s) that are contributors to the work.

## Folio / MARC

- 1XX field (Primary contributor/Creator only)
- 7XX field(s)

## Contributors

![Contributors drop-down showing Person, Family, Corporate body, Jurisdiction, Conference options](../images/page021_img01.png)

The available categories are:

- Person
- Family
- Corporate body
- Jurisdiction
- Conference

## Search LCNAF

Key in the person, family, corporate body, jurisdiction, or conference that you are searching for.

![Search LCNAF interface with NAF Corporate Name tab selected](../images/page021_img02.png)

In Folio this would be the same as Browse Contributors.

![Folio Browse inventory interface showing Contributors option](../images/page021_img03.png)

To see the full authority record for any name in the list, highlight the name and the authority record will appear in the right-hand panel.

![Search results with authority record detail panel showing variants and associated information](../images/page022_img01.png)

When you have identified the correct name, click on **Add [Shift+Enter]**.

![Search results with Add button highlighted in the authority record panel](../images/page022_img02.png)

The URI associated with the name will be added to Marva.

![Contributors showing linked corporate body name with "Linked" indicator](../images/page022_img03.png)

## Relationship Designator

Select a value from the drop-down list.

![Contributors with relationship designator drop-down showing options like abridger, actor, adapter](../images/page022_img04.png)

To add additional Contributors, add additional components for Contributor.

![Lightning bolt menu showing Add Another Component, Promote Contributor, Delete Component, Move Down options](../images/page023_img01.png)

![Multiple Contributors components showing different corporate bodies and a person, each with relationship designators](../images/page023_img02.png)

If there is a second appropriate relationship designator for any of the contributors, just add it in the same field.

![Contributor with two relationship designators: contributor and illustrator (ill)](../images/page023_img03.png)

To change any of the names you selected as the Contributors, click on the **X** next to the name and search for the correct name. To change or delete the relationship designator, click on the **X** next to the term.
