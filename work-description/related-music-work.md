# Music Related Work

A Music Related Work is a variation on a Hub that can include additional information about the resource, like the name of an arranger or a thematic index number. This option only appears when cataloging Notated music resources.

## Create Music Related Work

![Add Music related work template in Marva](../images/image-1786474210386.png)

To input a Music related work, click the action button and select the "Create Music Related Work" option.

![Add Music related work template with action button and Create Related Music Work option highlighted](../images/image-1786474808793.png)

A blank template will appear. Complete with the information appropriate for the resource. When finished, click the "Post" button to add the work to the BIBFRAME database.

![Create Related Music Work template with sample data included](../images/image-1786475446798.png)

After the work has been posted, the title will appear in the template. Add "part" as the relationship designator.
![Add Music related work template with "Sonata in E-flat major" as the title and "part" as the Relationship designator](../images/image-1786475554538.png)

## Edit Music Related Work

After the work has been posted, it can be edited. Select the "Edit Related Music Work" option under the lightning button.
![Add Music related work template with action button and Edit Related Music Work options highlighted](../images/image-1786476083724.png)

## Create New Related Music Work Based on Existing

If the resource includes several works with minor variations, like different keys or thematic numbers, the data in an already-created work can be used as a template for a new work.
![Add Music related work template with action button and Create New Related Music Work Based on Existing options highlighted](../images/image-1786476584220.png)

The existing data can be modified for the new work, and then posted as a new related work.

## Use existing Related Music Work

If the Related Music Work already exists in the BFDB, it can be retrieved when cataloging a different resource.

From an empty "Add Music related work" template, input the title in the "Search related work" box and select the title.

![Search results for Passacaglia](../images/image-1786550430975.png)

Click the "add" button and the title will display in Marva. Add a Relationship designator to complete the template.
![Marva display of Music related work "Passacaglia ; arranged" and relationship designator "part"](../images/image-1786550607813.png)
